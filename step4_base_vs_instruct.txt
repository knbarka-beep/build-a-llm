Observations
- The base model continues text. It never answers "What is 2+2?" as a question. Run 1 went on to a square root, run 2 wrote a blog-style post, run 3 gave "4" and then invented a multiplication lesson.
- Paris prompt on the base model: run 1 is a list of invented place names with kilometre numbers, run 2 mixes real places with made-up facts (it ends with the Nobel Prize), run 3 gives landmarks with false history (Pont Neuf "under the Eiffel Tower"). Same prompt each time, and the kind of output changes every time.
- The Human/Assistant trick made the base model look like an assistant for one answer. That answer is wrong (it says the atmosphere "re-emits red light as blue light" and that blue light "cannot be absorbed by our eyes"). Then it kept writing both sides of the conversation and drifted off. It was never trained to take one turn and stop.
- Nobel prompts: the base model says William Faulkner for both 2020 and 2026. Faulkner won in 1949 and died in 1962. For 2026 it answers confidently about something it cannot know, because its training data ends earlier. Fact check is in the Nobel section above.
- SmolLM2-135M-Instruct is not a clean win over the base model. It does answer in the format of an assistant (an introduction and a list for Paris, and it ends 2+2 with "equals 4" in runs 1 and 3). But the reasoning is nonsense ("2 + 2 = 2 * 2", "2 + 3 = 5" in a 2+2 question), run 2 on 2+2 never states an answer, and Paris run 3 falls into a loop repeating "the Eiffel Tower, the Arc de Triomphe". It also invents facts: "Arc de Triomphe ... designed by Jean-Georges Noverre in 1860", "Palais Garnier (1994): A former hotel", "Arc de Triomphe duaville: a Romanesque church dedicated in 1908".
- So instruction tuning changes the behaviour (it answers instead of continuing), but not how much the model knows. At 135M parameters the knowledge and reasoning are weak either way.
- The 360M-Instruct extra runs are cleaner: short, correct 2+2 three times, Paris lists in a stable format. It still hallucinates: Versailles is described as "the setting of the 1981 film The Godfather starring Al Pacino", and Notre-Dame is listed twice (Cathedral and Basilica).
